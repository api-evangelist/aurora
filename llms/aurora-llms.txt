# Aurora

> Aurora is an EVM-compatible blockchain platform for launching fully customizable Virtual Chains that run as smart contracts on the NEAR Protocol. It pairs full Ethereum tooling compatibility with NEAR's low fees, sub-second block times, and fast finality. The primary developer surface is an Ethereum-compatible JSON-RPC 2.0 API on public mainnet and testnet endpoints.

This llms.txt was generated by the API Evangelist enrichment pipeline (method: generated) from apis.yml and the artifacts in this repository. Source of truth is https://doc.aurora.dev/.

## API

- [Aurora JSON-RPC API — mainnet](https://mainnet.aurora.dev): Ethereum-compatible JSON-RPC 2.0 endpoint, chain ID 1313161554. Standard eth_* methods over HTTPS and WebSocket. No API key required.
- [Aurora JSON-RPC API — testnet](https://testnet.aurora.dev): Testnet endpoint, chain ID 1313161555. Free test funds via faucet.
